Step 1 — Write your data model on paper

Keep it stupidly small initially:

    users
      id
      name
      email

    events
      id
      name
      venue
      start_time
      capacity

    bookings
      id
      user_id
      event_id
      created_at

Then ask yourself:

    "What REST endpoints would I need to make this work?"

For example:

    GET  /events
    GET  /events/:id

    GET  /users/:id/bookings

    POST /events/:id/book

    DELETE /bookings/:id

Don't Google implementation yet.
Try to figure out what each endpoint should receive and return yourself.
